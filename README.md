珈琲フロートコレクティブ 公式ポータル（初版）
================================================

内容
- index.html : トップページ
- style.css  : デザイン・レスポンシブ対応

公開方法（GitHub Pages）
1. GitHubで新しいPublicリポジトリを作成します。
   例: coffee-float-collective
2. index.html と style.css をリポジトリ直下にアップロードします。
3. Settings → Pages → Build and deployment で「Deploy from a branch」を選択。
4. Branch を main、folder を /(root) にして Save。
5. 表示された https://ユーザー名.github.io/リポジトリ名/ が公開URLです。

公開前に必ず行うこと
- 「リンク設定待ち」「リンク先は仮リンク」と書かれた箇所を、実際の販売・SNS URLに差し替える。
- 作品説明、発売状況、プロフィール文を確認する。
- 作品画像を使う場合は、権利を確認した画像に差し替える。
- Google Fontsを読み込んでいます。外部通信を避けたい場合はCSSの@importを削除し、端末標準フォントに変更してください。

このサイトは静的HTML/CSSのみで構成されています。PHP、WordPress、データベースは不要です。
